ด้านบนเป็น Banner ขื่อร้าน

จอกว้าง - ลงมาจาก Banner เป็นหมวดหมู่ มีตะกร้าด้านขวา (Nav Bar) 
จอแคบ - ด้านซ้ายของ Banner มี (hamburger dropdown menu)

จอกว้าง - สมุดวางขึ้นก่อน ตามด้วยปากกา ด้านขวา
จอแคป - สมุดอยู่บน ปากกาอยู่ล่าง

เครื่องมือและเหตุผล :
- ใช้ Flex box สำหรับจอกว้าง เพื่อให้ เมนู เรียงต่อกันได้ ทั้งแบบ เรียงปกติ ทั้งแบบ Hamburger dropdown menu
ส่วน สินค้า จะใช้ grid เพื่อกำหนดจำนวน สินค้าที่จะ ต่อกัน ได้แถวนั้นๆได้
